Machine Learning

How we verify deals.

A two-tiered anomaly detection system ensures alerts are only triggered for genuine market shifts, saving API costs and maintaining user trust.

  • Layer 1: MAD (Fast Path)
    Median Absolute Deviation. Sub-millisecond execution. Catches 99% of straightforward price drops.
  • Layer 2: Isolation Forest (Deep)
    Pre-trained unsupervised model. Analyzes historical TimescaleDB data for subtle manipulation.
