### Review resolution (5 rounds)

The PR review agent was run 5 times. All legitimate findings were addressed
round-by-round:

- **Unpinned :latest images** → pinned Prometheus (v2.53.0) and Grafana
  (11.1.0).
- **Missing healthchecks** → added healthchecks for Prometheus and Grafana.
- **Missing depends_on** → added `depends_on` for database exporters.
- **DEMO_MODE defaults to true** → changed to `false`.
- **Backfill not in a transaction** → wrapped in `BEGIN`/`COMMIT`.
- **Invalid dim_date week values** → added `GREATEST`/`LEAST` bounds.
- **fact_price_history not a hypertable** → added `create_hypertable`.
- **dim_product multiple current rows** → added partial unique index
  `uq_dim_product_one_current`.
- **Legacy schema.sql has analytics tables** → removed them (now in
  `infra/sql/schema/timescaledb.sql`).
- **Grafana no admin password** → added `GF_SECURITY_ADMIN_PASSWORD`.
- **Exporter restart policies** → added `restart: unless-stopped`.
- **DB exporter connection string** → fixed to use full
  `postgresql://user:pass@host:port/db` format.
- **Monitoring DB role not provisioned** → added
  `infra/sql/migrations/postgres/0001_monitor_role.sql`.
- **.env.example concrete credentials** → removed default passwords.
- **Documentation date in the future** → fixed to October 2025.
- **Missing trailing newlines** → added.

The remaining recurring findings are documented trade-offs / out-of-scope
for this PR:

1. **Prometheus/Grafana exposed on host ports** — accepted trade-off for
   local dev; production deployments should use reverse proxies with
   authentication.
2. **SSL disabled in exporter connections** — internal Docker network;
   SSL is not required for container-to-container communication.
3. **Financial records deleted on user deletion** — design decision in the
   new `postgres.sql` schema (out of scope for this PR).
4. **Admins table VARCHAR(36) PK** — follows the established project
   convention (out of scope for this PR).
5. **Missing integration tests** — the monitoring stack is infrastructure
   configuration, not application code; covered by CI lint + the existing
   backend test suite (520 passed).
6. **Migration ordering manual** — follows the existing project convention
   (numbered files applied in order).

CI green. Full backend suite: **520 passed / 1 skipped**.
